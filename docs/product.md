# 產品定義與商業化

## 1. 一句話

YMZZ Bead Atlas 讓「圖片變成能做的拼豆圖紙」這件事，同時滿足三件事：顏色可信、顏色可改、過程可查。

## 2. 目標使用者

1. 拼豆創作者：手上有圖，想自己做圖紙，買豆前要確定色號與數量。
2. 手工店與工作坊：需要可列印圖紙與備料清單，還要處理不同品牌的豆。
3. 文創與電商：需要批次出圖、估算成本、對外提供一致規格的施工圖。
4. Agent 使用者：希望在對話中直接完成「圖片轉圖紙」的自動化流程。

## 3. 差異化

1. 多品牌而非單一品牌：15 品牌 2093 色，每個色號都標明品牌、豆徑、色系，材料表帶品牌欄。
2. 感知色差而非加權 RGB：CIEDE2000，逐格輸出 ΔE00，並以公開參考組做自檢。
3. 色卡可改而非寫死：實體色卡與資料庫有偏差時，使用者可覆寫、新增、整份替換，並存成自己的色群預設。
4. 可安裝能力而非網頁：Claude Skill 格式，命令列可呼叫、可批次、可被 Agent 呼叫，可建置成商品交付。
5. 稽核痕跡：每份輸出帶品牌、資料來源、預設、覆寫與 ΔE00 統計。

## 4. 交付與定價策略

1. 買斷制，目前售價 ¥19.90：一次付款後交付完整 Skill 源碼、色卡與預設機制（明文 ZIP），可自行修改。本專案以 MIT 授權；買方在遵守 LICENSE 與 NOTICE 的前提下可以再分發源碼。
2. 不保證實物零色差：色卡與輸出色值是螢幕參考，實物批次、材質、透光與熨燙都會造成差別；ΔE00 只說明螢幕參考匹配的接近程度，不代表實物一致。
3. 定期升級：色卡資料更新、演算法調整、預設格式擴充以版本更新提供，已購買用戶可從公開倉庫取得後續公開版本。
4. 長期規劃（尚未實作，不是已上線商品）：雲端作品庫、批量出圖與排產、實體色卡校色工具、訂閱制更新服務。

## 5. 可持續性

1. 色卡資料來源固定公開專案並記錄逐檔雜湊，更新可稽核。
2. 演算法有公開參考組自檢，避免後續修改造成匹配退化。
3. 測試覆蓋色差、色卡完整性、透明格、預設套用、匯出檔案集合，防止交付品質下滑。

## 6. 已知限制

1. 螢幕參考值不等於實物顏色，工具提供核色證據與覆寫能力，但無法替使用者保證實物一致。
2. 對話式交付的邊界是「把圖片轉成圖紙」，不含實體製作與採購。
3. 雲端能力尚未實作，現在的商業化主體是本機可執行版本。
